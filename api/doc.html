SDK Documentation

Getting Started

The Orbinuity SDK enables 3rd-party web applications to authenticate users and persist application-specific JSON data using their Orbinuity account.

1. Include the SDK:

<script src="https://orbinuity.nl/api/sdk.js"></script>

2. Initialize with your App Key:

const sdk = new OrbinuitySDK('yourAppKey');

API Methods

getUserInfo()

Fetches the profile info of the currently logged-in user.

const user = await sdk.getUserInfo();

get()

Retrieves stored JSON data associated with your appKey for the user.

const data = await sdk.get();

save(payload)

Saves or updates a JSON object for your appKey on the user's account.

await sdk.save({ score: 1250, level: 4 });

User Profile Schema

Structure returned by getUserInfo():

Field Type Description
id string Unique user account ID timestamp.
username string Unique account username handle.
displayName string Public display name.
age number | null User age (if provided).
pronouns string | null Preferred pronouns (if provided).
country string | null Country code or name (if provided).
createdAt string ISO creation timestamp.

Complete Implementation Example

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>3rd Party App</title>
    <script src="https://orbinuity.nl/api/sdk.js"></script>
</head>
<body>

    <h1 id="user-display">Loading...</h1>
    <button onclick="saveProgress()">Save High Score</button>

    <script>
        const sdk = new OrbinuitySDK('myGameApp');

        async function init() {
            try {
                // Fetch User Profile
                const user = await sdk.getUserInfo();
                document.getElementById('user-display').textContent = `Welcome, ${user.displayName}!`;

                // Fetch App Data
                const gameData = await sdk.get();
                if (gameData) {
                    console.log('Restored score:', gameData.score);
                }
            } catch (err) {
                document.window.open('https://orbinuity.nl/account/login', '_blank')
            }
        }

        async function saveProgress() {
            try {
                await sdk.save({ score: 5000, level: 10 });
                alert('Saved to Orbinuity account!');
            } catch (err) {
                alert('Save failed: ' + err.message);
            }
        }

        init();
    </script>

</body>
</html>
